# Аналитика каталога стримингового сервиса

Набор функций для анализа каталога фильмов: статистика, категории, отчёты по жанрам и актёрам, топ по рейтингу. Запуск печатает итоговый отчёт по каталогу.

## Запуск

```bash
uv sync
uv run catalog_analysis.py
```

## Проверка стиля

```bash
uv run ruff check .
```
